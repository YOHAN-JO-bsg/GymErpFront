# Gym ERP (Frontend)

> Gym ERP 시스템의 사용자 화면을 담당하는 프론트엔드 저장소

<br>

## 기술 스택 (Tech Stack)
* React, JavaScript, Axios, HTML5, CSS3

<br>

## 주요 역할
* 백엔드 REST API 연동 및 데이터 바인딩
* 판매·매출 도메인 화면 CRUD 구현
* 공통 검색/선택 UI 컴포넌트 구현
* 페이징, 모달 기반 사용자 인터랙션 처리

## 실행 방법
```bash
# 1. 저장소 복제
git clone [https://github.com/사용자아이디/FE저장소명.git](https://github.com/사용자아이디/FE저장소명.git)

# 2. 패키지 설치
npm install

# 3. 개발 서버 실행
npm run dev
